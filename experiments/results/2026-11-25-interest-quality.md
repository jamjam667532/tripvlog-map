# 관심사 추출·임베딩 품질 시험 (2026-11-25, 결정 0011)

스크립트: `experiments/interests/quality.py`(추출 + 유사도), `variants.py`(관심사 벡터 개선안 비교).
실행: `cd backend && PYTHONPATH=. uv run python ../experiments/interests/quality.py ../experiments/.env`
학교 게이트웨이: 관심사 추출 `bedrock-haiku`(생각 끔), 임베딩 `bedrock-titan-embed-v2`(1024차원).

**한계:** 예시 사용자 1명(구독 16개, 좋아요 5개), 후보 영상 8개. 방향을 정하는 시험이고, 실제 구독 목록으로 다시 확인해야 한다.

## 1. 관심사 추출 (Bedrock 1회, 2.4초)

예시 구독: 건축 5, 역사·교양 3, 애니 4, 무관(게임·코딩·재테크·운동) 4.

| 관심사 | 비중(근거 수) | 여행 검색어 |
| --- | --- | --- |
| 건축 | 0.47 (채널 5 + 좋아요 2) | 건축 투어, 건축 답사 여행, 현대 건축 명소 |
| 애니메이션·오타쿠 문화 | 0.27 (4) | 애니 성지순례, 오타쿠 여행, 피규어 쇼핑 투어 |
| 역사 | 0.20 (3) | 역사 여행, 박물관 투어, 고성 답사 |
| 인문·미술 | 0.07 (1) | 미술관 여행, 인문 산책 |

무관 채널은 모두 걸러졌고, 근거 ID는 전부 입력에 있는 값이었다.

## 2. 영상 유사도: 관심사 벡터 개선안

정답: 건축 투어·오모테산도 현대건축 → 건축, 국립박물관 에도 시대 → 역사, 아키하바라 → 애니, 라멘·이자카야·디즈니·카페 → 선택 안 함. 기준 점수 0.25.

| 방식 | 맞음 | 놓친 것 |
| --- | --- | --- |
| 짧은 문장 1개, 보정 0.6+0.4w | 6/8 | 오모테산도 건축(0.18), 박물관 에도(0.10, 역사 대신 인문) |
| A. 관심사 문장 + 근거 글 평균, 보정 0.8+0.2w | 7/8 | 오모테산도 건축(0.23) |
| **A+B. A + 검색어 단어 일치 +0.15** | **8/8** | 없음 |

- A: 근거 글("에도 시대 역사 한 번에 정리")이 관심사 벡터에 들어가자 박물관 영상이 역사로 잡혔다(0.13 → 0.26).
- B: 임베딩이 약하게 본 "현대건축"을 단어 일치가 보완했다(0.23 → 0.38).
- 오탐(라멘·이자카야·디즈니·카페)은 세 방식 모두 기준 아래.
- 임베딩 토큰: 비교 전체 808.

**코드 반영:** A+B. `functions/api_me` 관심사 벡터 = 문장 + 근거 글(최대 10개) 평균, `rules/interests.theme_score` 보정 0.8+0.2w와 단어 일치 가산.
