# 0001. 핵심 결정 (2026-10-14)

상태: 확정

## 결정
1. 동선·일정·방문 순서·경로·기간 입력은 만들지 않는다. 대신 영상 근거 기반 방문 시간대 근거를 제공한다.
2. 로그인은 선택이다. 비로그인은 `/public/*`, 로그인은 JWT가 걸린 `/jobs`, `/me/*`로 경로를 분리한다.
3. 비로그인 작업 접근은 jobId가 아니라 별도 guestAccessToken으로 하고, DB에는 SHA-256 해시만 저장한다.
4. Google OAuth 토큰은 저장하지 않는다. 연결 시 1회 조회하고 25~30일마다 재연결한다.
5. 시간 근거는 SCENE / STATED_TIME / WAIT_EXPERIENCE / CREATOR_TIP으로 구분하고, 장면 관찰만으로 추천하지 않는다.
6. 영상 재생 위치(videoTimeRange)와 실제 방문 시각(visitTimeEvidence.localClockTime)을 분리한다.
7. Jobs는 videoRefs(videoId + analysisVersion)로 분석 결과를 참조하고, Places 근거 키에도 analysisVersion을 넣는다.
8. Bedrock은 US 리전 하나에 전체 스택을 둔다. 모델: Haiku 4.5(해석 주력), GPT 5.6 Luna(비교), Nova Micro(스타일 분류), Nova Lite(조건부 대체 모드).

## 이유
기획서(docs/기획서.md)의 기술 스펙·아키텍처·리스크 섹션과 Claude·GPT 교차 검토 결과를 따른다.
