# 0011. 관심사 임베딩 기반 테마 추천 (2026-11-25)

상태: **확정** (2026-11-25, 사람 결정. 영상 구성은 관심사 3 + 일반 2, 구독 전체 제목을 게이트웨이로 보내고 연결 화면에 안내)

결정 0010(개정 2)의 "여행 채널 + 여행 스타일 5종" 취향을 넘어선다. 0010의 구독·좋아요 조회, 채널 라벨, 개인 채널 영상, 사용자 수정 우선 원칙은 그대로 쓴다.

## 문제

여행 스타일 5종(맛집·카페·관광·쇼핑·가성비)으로는 사람의 관심사를 담지 못한다. 서비스 의도는 이렇다.

- 역사·교양 채널을 많이 구독 → **역사 테마 여행** 영상
- 건축 채널을 많이 봄 → **도쿄 건축 투어** 영상
- 애니·서브컬처 구독·좋아요 → **성지순례·오타쿠 투어** 영상

즉 **여행과 상관없는 구독·좋아요 전체**에서 관심사를 뽑고, 그 관심사에 맞는 **테마 여행 영상**을 찾아 분석한다.

## 확인한 것

학교 게이트웨이에 임베딩 모델 `bedrock-titan-embed-v2`가 있다(2026-11-25, `/models`). 1024차원, 문장 4개에 77토큰. "도쿄 건축 여행" 기준 유사도가 "안도 다다오 건축 투어" 0.34 > "라멘 먹방" 0.21 > "애니 성지순례" 0.04로 의미 순서가 맞았다.

## 결정

### 1. 관심사 추출 (유튜브 연결할 때 1번)

| 단계 | 담당 | 내용 |
| --- | --- | --- |
| 입력 | 코드 | 구독 채널 전체(최대 200)와 좋아요 영상(최대 100)의 제목·설명(앞부분) |
| 관심사 제안 | Bedrock | 관심사 3~5개. 각각 짧은 이름, **근거 채널·영상 ID**, 여행 검색어 1~3개 |
| 검증 | 규칙 | 근거 ID가 입력에 있는 것만 인정, 근거 없는 관심사는 버림. 비중은 근거 수로 계산(AI가 정하지 않음) |
| 벡터 | 임베딩 | 관심사마다 "이름 + 검색어"를 임베딩 |
| 저장 | Users | `youtube.interests`(이름, 비중, 검색어, 근거 ID, 벡터). 유튜브 데이터라 25일 뒤·연결 해제 시 삭제 |
| 수정 | 사용자 | 화면에서 관심사를 끄거나 고칠 수 있다(고친 값이 우선) |

라벨 호출과 관심사 호출은 **병렬**로 한다(API Gateway 30초 제한).

### 2. 영상 찾기와 고르기 (검색할 때)

- 기본 검색 3개에 **상위 관심사 2개의 테마 검색**("도쿄 건축 여행")을 더한다. 도시+검색어 단위로 25일 캐시, 하루 검색 상한 안에서.
- 후보 영상의 제목·설명을 임베딩한다(영상마다 25일 캐시). 점수 = 관심사 벡터들과의 코사인 유사도(관심사 비중 반영) 중 최댓값.
- **구성: 관심사 3 + 일반 2.** 개인화 자리 3개는 구독 여행 채널 영상(결정 0010) → 관심사 유사도 순으로 채우고, 유사도가 기준 미만이면 채우지 않는다. 나머지는 일반 검색 순서로 채운다. 처음 가는 도시의 대표 장소가 빠지지 않게 하려는 것이다.
- 영상마다 어떤 관심사로 골랐는지(`theme`)와 점수를 작업에 기록한다.

### 3. 장소 순위

장소는 자기가 나온 영상의 관심사 점수를 물려받는다(가장 높은 값). 기존 점수에 `점수 × THEME_WEIGHT`를 더한다. 결과에 장소별 관심사 이름(`themes`)을 담아 화면에서 "건축 관심사로 찾은 곳"을 보여 줄 수 있게 한다.

## 비용

| 항목 | 비용 |
| --- | --- |
| 관심사 추출 | 연결할 때 Bedrock 1회 |
| 임베딩 | 관심사 3~5개 + 새 후보 영상. 영상 단위 캐시. 매우 싸다 |
| YouTube 검색 | 로그인 작업마다 최대 2회 추가(각 100 unit), 캐시가 있으면 0 |
| 분석(Gemini) | 요청당 최대 5개 그대로 |

## 개인정보

여행 채널만이 아니라 **구독 전체의 제목·설명**이 학교 게이트웨이로 간다(요청 로그가 일정 기간 남는다). 사용자 ID·이메일·토큰은 보내지 않는다. **연결 화면에 "관심사 분석을 위해 구독 채널 제목을 학교 AI 게이트웨이로 보냅니다"를 안내한다**(프론트 작업). 관심사 벡터는 사용자 데이터라 25일 보관 후 삭제한다.

## 대안 (채택하지 않음)

- **관심사만으로 5개:** 처음 가는 도시의 대표 명소가 빠질 수 있다.
- **스타일 5종 확장만:** 관심사(건축, 애니 …)를 미리 다 정할 수 없다.
- **협업 필터링:** 사용자가 적어 데이터가 없다.
- **임베딩 없이 키워드만:** "안도 다다오"와 "건축"처럼 단어가 다른 같은 관심사를 못 잇는다.
